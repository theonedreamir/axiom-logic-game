# AXIOM

A monochrome logic puzzle about building stable, contradiction-free systems.

## Play

Open `index.html` or use the live GitHub Pages deployment.

## Rules

Each case is a network of premises and logical rule nodes. Toggle a premise and the entire graph recalculates. Satisfy every required observation within the move budget to certify the system.

Five handcrafted cases introduce XOR, AND, NOT, parity and simultaneous constraints. Scoring rewards par solutions.

## Stack

Vanilla HTML, CSS and JavaScript. No dependencies, backend, accounts or network calls.
